# Changelog

## 0.2.0 — 2026-07-30

- Added delegate-backed location authorization requests.
- Preserved configured photo access levels and notification options in native requests.
- Added permission dependency planning, default user explanations, opt-in lifecycle event hooks, and concurrency regression coverage.
- Added dependency-aware, de-duplicated group requests with cancellation handling.
- Added bounded, in-memory request history for dashboards and diagnostics.
- Added automatic application-activation refresh on Apple platforms, runtime capability diagnostics, a permission dashboard, and observation regression coverage.
- Added privacy-safe, Codable audit reports with stable JSON round trips.
- Added dependency-aware onboarding plans and deterministic multi-permission mock scenarios.
